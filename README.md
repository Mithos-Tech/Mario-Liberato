## 🧭 Pilares de Especialización

El portafolio se estructura en tres marcas y áreas operativas complementarias:

* **Sistemas y servidores:** Windows Server, Active Directory y distribuciones Linux (Ubuntu, Red Hat, Kali) en entornos virtualizados.
* **Impacto comprobado:** Optimización documentada (+20% de disponibilidad de equipos mediante rutinas de mantenimiento preventivo semanal).

### 2. Inspyrio Studio · Diseño y Desarrollo Web
Proyectos web responsivos, interfaces cinemáticas y experiencias digitales de vanguardia:
* **[Zyvara](https://zyvara-venues.vercel.app/)** — *Espacios exclusivos*: Plataforma editorial y catálogo de locaciones para eventos y producciones de alta gama.
* **[Luvox](https://luvox-vet.vercel.app/)** — *Clínica veterinaria*: Sitio web de atención integral con flujos claros de servicios médicos y citas.
* **[Bloom](https://bloom-studio-v1.vercel.app/)** — *Estudio creativo*: Portafolio de diseño con microinteracciones y tipografía de precisión.

### 3. Inspyrio Labs · Agentes de Inteligencia Artificial
* **Automatización conversacional:** Desarrollo e integración de agentes inteligentes y flujos autónomos (WhatsApp Business API, n8n, Supabase).
* **Modelos avanzados:** Integración de APIs de lenguaje natural (Claude API, OpenAI, Gemini) para soporte automatizado 24/7.

## 🛠️ Stack Tecnológico y Arquitectura

* **Frontend:** React 19, TypeScript, Vite.
* **Estilos:** Tailwind CSS y CSS modular personalizado con paleta editorial oscura (`#0a0a0e`, acentos cálidos `#ff4a1c` y grises de alto contraste).
* **Tipografía:** Montserrat (títulos, UI de precisión) y DM Serif Display (acento editorial cursivo).
* **Multimedia & CDN:** Cloudinary CDN para streaming de video y renderizado optimizado de WebP.
* **SEO & Metadata:** OpenGraph completo, Twitter Cards y marcado estructurado Schema.org JSON-LD (Person & WebSite).

## 🚀 Instalación y Desarrollo Local

### Requisitos previos
* [Node.js](https://nodejs.org/) (versión 18 o superior)
* Gestor de paquetes `npm` o `bun`

### Pasos

1. Clonar el repositorio:
   ```bash
   git clone https://github.com/Mithos-Tech/mario-liberato-portfolio.git
   cd mario-liberato-portfolio
   ```

2. Instalar dependencias:
   ```bash
   npm install
   ```

3. Iniciar el servidor de desarrollo local:
   ```bash
   npm run dev
   ```

4. Compilar para producción:
   ```bash
   npm run build
   ```
